# Storage Deep Dive

The storage layer persists writes to a write-ahead log before acknowledging the client, and a background compaction thread periodically merges on-disk segments to reclaim space. Under sustained write pressure the compaction queue grows, which can briefly raise tail latencies until the queue drains. Operators tune the compaction budget to trade steady-state throughput against burst absorption, and most production deployments settle somewhere in the middle, accepting a modest tail-latency ceiling.
