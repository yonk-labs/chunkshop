## How to use the new surfaces

### Ingest a GitHub repo (verified, PAT auth)

```yaml
# repo.yaml
cell_name: my_repo_ingest
source:
  type: connector
  connector: github
  config:
    owner: myorg
    repo: myrepo
    branch: main
    paths_glob: ["**/*.py", "**/*.md"]
    # token: optional; falls back to ${GITHUB_TOKEN}
  sync: {mode: cursor}
chunker:
  type: symbol_aware
  granularity: function
  include_imports: true
extractor:
  type: composite
  extractors:
    - {type: code_summary, backend: lede}
    - {type: code_relationships}
embedder:
  type: fastembed
  model_name: Xenova/bge-small-en-v1.5-int8
  dim: 384
target:
  type: postgres
  dsn_env: CHUNKSHOP_DEMO_DSN
  database: myrepo_kb
  table: chunks
  mode: overwrite
  promote_metadata:
    - {path: symbol_name, type: text}
    - {path: fqn, type: text}
    - {path: symbol_type, type: text}
    - {path: language, type: text}
    - {path: summary, type: text}
    - {path: start_line, type: int}
    - {path: end_line, type: int}
```

```
chunkshop ingest --config repo.yaml
chunkshop search --config repo.yaml --query "vector embedding"
```

Once SP-E lands:

```
chunkshop search --config repo.yaml --query "vector embedding" --by-symbol HttpSource
chunkshop impact-of --config repo.yaml --fqn chunkshop.sources.http.HttpSource.iter_changes_since --depth 2
```

### Ingest a Google Drive folder (real OAuth)

Set up Google Cloud OAuth client (Desktop type) with redirect
`http://localhost:8765/callback`. Enable the Drive API. Export
`GDRIVE_CLIENT_ID` and `GDRIVE_CLIENT_SECRET`.

```bash
python python/connectors/examples/e2e_gdrive_real_flow.py \
  'https://drive.google.com/drive/folders/<ID>' \
  --chunker hierarchy --extractor composite_keywords_lang
```

Tokens cache at `~/.chunkshop/gdrive-tokens.json` and refresh proactively
within the leeway window.

### Crawl a URL with depth + incremental

```yaml
source:
  type: http
  urls: ["https://example.com"]
  crawl_depth: 2
  allow_external: false
  respect_robots: true
  max_pages: 100
  user_agent: "chunkshop/0.5"
sync: {mode: cursor}
```

Cursor shape: `{<url>: {etag: ..., last_modified: ...}}`. Conditional
GETs on re-sync skip unchanged URLs (304 Not Modified).
