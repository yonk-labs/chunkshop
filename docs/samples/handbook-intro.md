# Welcome to Northwind Co.

This handbook is the single source of truth for how Northwind operates. It covers
engineering conventions, security posture, and release process. Read the section you need;
the rest will be here when you come back.

## What we do

Northwind builds internal tooling for mid-market logistics operators. Our customers run
warehouses between 50k and 500k square feet and ship physical goods. We are not a
consumer-facing company. Everything we write is eventually looked at by someone doing
their job, not someone scrolling for fun.

## How this handbook is structured

Each top-level heading in this document and its siblings is a self-contained topic. When
in doubt, scan the table of contents rather than searching body text — we keep headings
explicit so that retrieval tools can use them as anchors.
